# Automatic File Sorter
## Overview

This project automates the organization of files within a directory by sorting them into folders based on their extensions. It supports `.csv`, `.txt`, `.xlsx`, and `.json` files.

## Features

- **File Type Sorting:** Moves files into separate folders for each supported file type.
- **Folder Creation:** Automatically creates folders if they do not exist.
- **File Movement:** Safely moves files to their respective folders without overwriting existing files.

## Requirements

- Python 3.x
- `os`, `shutil`, and `pathlib` libraries

## Usage

1. Clone the repository.
2. Update the `path` variable in the code to point to your target directory.
3. Run the Python script.
